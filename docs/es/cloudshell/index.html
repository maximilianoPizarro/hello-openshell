OpenShell desde Cloud Shell

Cloud Shell ya trae minikube. El clúster corre en esa VM y no crea un GKE. El gateway levanta con containerd 2. El sandbox no: este kernel no tiene CONFIG_SECURITY_LANDLOCK.

1Arrancar minikube

Administrás este clúster, así que podés instalar el CRD de Agent Sandbox. No uses deploy/openshift-scc-values.yaml. Ese archivo es para la SCC restricted-v2 de OpenShift.

El runtime Docker de este host fue docker://29.2.1. No anuncia supplementalGroupsPolicy, y el Strict del sandbox termina en SupplementalGroupsPolicyNotSupported. Cloud Shell exporta MINIKUBE_FORCE_SYSTEMD=true. Con containerd 2.2.1, runc pide slice:prefix:name y el kubelet, con cgroups-per-qos=false, manda /k8s.io/.... El control plane no escucha. El kubelet igual informa NodeHasNoDiskPressure.

MINIKUBE_FORCE_SYSTEMD=false minikube start --driver=docker --container-runtime=containerd --force-systemd=false

Si kubeadm sigue esperando a los cuatro minutos y el log del kubelet nombra slice:prefix:name, pasá containerd a cgroupfs. El intento siguiente puede terminar. Seguí solo si el nodo imprime containerd://2 y strict=true.

docker exec minikube sed -i 's/SystemdCgroup = true/SystemdCgroup = false/' /etc/containerd/config.toml
docker exec minikube systemctl restart containerd
docker exec minikube systemctl restart kubelet
kubectl get node minikube -o jsonpath='runtime={.status.nodeInfo.containerRuntimeVersion}{"\n"}strict={.status.features.supplementalGroupsPolicy}{"\n"}'

2Agent Sandbox y el gateway

El chart no instala el CRD. Si falta helm, instalá Helm 3 antes.

kubectl apply -f https://github.com/kubernetes-sigs/agent-sandbox/releases/download/v1.0.10/sandbox.yaml
kubectl -n agent-sandbox-system rollout status deployment/agent-sandbox-controller --timeout=180s
helm upgrade --install openshell \
  oci://ghcr.io/nvidia/openshell/helm-chart \
  --version 0.1.8 \
  --namespace openshell \
  --create-namespace
kubectl -n openshell rollout status statefulset/openshell --timeout=300s

3CLI y mTLS

Cloud Shell es Debian. Usá el binario musl, no el instalador de Fedora. Dejá el port-forward en otra terminal. El nombre del directorio tiene que coincidir con el del gateway.

mkdir -p "${HOME}/.local/bin"
curl -fL https://github.com/NVIDIA/OpenShell/releases/download/v0.1.8/openshell-x86_64-unknown-linux-musl.tar.gz \
  | tar -xz -C "${HOME}/.local/bin"
export PATH="${HOME}/.local/bin:${PATH}"
openshell --version
kubectl -n openshell port-forward svc/openshell 8080:8080
mkdir -p "${HOME}/.config/openshell/gateways/minikube/mtls"
kubectl -n openshell get secret openshell-client-tls -o jsonpath='{.data.ca\.crt}' | base64 -d \
  > "${HOME}/.config/openshell/gateways/minikube/mtls/ca.crt"
kubectl -n openshell get secret openshell-client-tls -o jsonpath='{.data.tls\.crt}' | base64 -d \
  > "${HOME}/.config/openshell/gateways/minikube/mtls/tls.crt"
kubectl -n openshell get secret openshell-client-tls -o jsonpath='{.data.tls\.key}' | base64 -d \
  > "${HOME}/.config/openshell/gateways/minikube/mtls/tls.key"
chmod 600 "${HOME}/.config/openshell/gateways/minikube/mtls/tls.key"
openshell gateway remove minikube
openshell gateway add https://127.0.0.1:8080 --local --name minikube
openshell gateway select minikube
openshell status

El primer gateway remove imprime No gateway metadata found for 'minikube'. El add de la línea siguiente igual registra los certificados de este clúster. openshell status queda en Connected para 0.1.8.

4Prueba

La imagen se baja. El contenedor agent sale con código 1 en el mismo segundo. El supervisor arranca y su readiness al puerto 5501 sigue rechazada. openshell-0 queda Running.

openshell sandbox create \
  --name model-check \
  --from registry.access.redhat.com/hi/python:3.12 \
  --policy deploy/hi-python.policy.yaml \
  -- /usr/bin/python3.12 -c 'print("ok")'
kubectl logs -n openshell default--model-check -c agent

Ese log es Landlock ABI v3 or newer (Linux 6.2+) is required, but Landlock is not implemented (kernel lacks CONFIG_SECURITY_LANDLOCK). El driver docker de minikube usa el kernel de Cloud Shell. Un sandbox necesita un kernel con Landlock ABI v3.

5Borrar el clúster

minikube delete

El archivo que abre el botón es docs/cloudshell-tutorial.md.
