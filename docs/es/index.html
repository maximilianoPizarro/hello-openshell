OpenShell en tu máquina

Un sandbox de Podman llama a Ollama llama3.2:1b por host.openshell.internal:11434. El gateway es OpenShell 0.1.8. El cliente es examples/ask.py.

Local

Podman en Linux, macOS o Windows. Tope de 3 GiB.

Developer Sandbox

CLI en Dev Spaces. Experimental; configurá tu URL del modelo.

OpenShift AI

Referencia de admin. Una GPU, el token queda en el gateway.

Cloud Shell

minikube dentro de Cloud Shell. Abrir en Cloud Shell.

0Quickstart

git clone https://github.com/maximilianoPizarro/hello-openshell
cd hello-openshell
make up
make gateway
make ask
make down

make up levanta Ollama y baja el modelo. make gateway instala OpenShell 0.1.8. make ask corre examples/ask.py en el sandbox de Python endurecido.

1Plataformas

PlataformaPodmanURL del host para OllamaGateway
LinuxNativohttp://127.0.0.1:11434En el host
macOSpodman machinePuerto publicado en localhostDentro de la machine
Windowspodman machine en WSL2localhost con mirrored, o IPv4 de la machine con NATDentro de la machine

scripts/ollama-url.sh imprime la URL del host. El sandbox siempre usa host.openshell.internal:11434. En Windows, networkingMode=mirrored en %USERPROFILE%\.wslconfig hace que localhost funcione desde el host.

2Importar el perfil de Ollama

openshell profile lint -f deploy/ollama.profile.yaml
openshell profile import -f deploy/ollama.profile.yaml
openshell provider create --name ollama --type ollama
openshell provider get ollama

3Listar modelos desde un sandbox

openshell sandbox create \
  --name model-check \
  --from registry.access.redhat.com/hi/python:3.12 \
  --provider ollama \
  --policy deploy/hi-python.policy.yaml \
  -- /usr/bin/python3.12 -c 'import urllib.request; print(urllib.request.urlopen(urllib.request.Request("http://host.openshell.internal:11434/v1/models", headers={"Authorization":"Bearer fake"})).read().decode())'

El JSON tiene que incluir llama3.2:1b. El usuario de la imagen es el UID 65532 y su grupo primario es 0, así que la política fija usuario y grupo en 65532.

4Preguntar con ask.py

export MODEL_NAME=llama3.2:1b
openshell sandbox create \
  --name hello-agent \
  --from registry.access.redhat.com/hi/python:3.12 \
  --provider ollama \
  --policy deploy/hi-python.policy.yaml \
  --env OPENAI_BASE_URL=http://host.openshell.internal:11434/v1 \
  --env "MODEL_NAME=${MODEL_NAME}" \
  --env OPENAI_API_KEY=fake \
  -- /usr/bin/python3.12 -c "$(cat examples/ask.py)"

5Bajar el laboratorio

make down
