Developer Sandbox

Abrí el repo en un workspace. Al arrancar se instala el CLI de OpenShell 0.1.8 y el workspace sigue abriendo si ese paso falla. Ejecutá Install OpenShell CLI para ver el error. Este clúster no puede alojar el gateway.

Abrir en Developer Sandbox

1Abrir el workspace

Usá el botón, o en el Developer Sandbox abrí Dev Spaces y creá un workspace con este repo. devfile.yaml pide 512Mi / 200m y limita el contenedor a 4Gi / 2 CPUs. El storage es efímero. Al arrancar corre scripts/install-openshell-cli.sh y deja openshell 0.1.8 en el PATH. El resto de las tareas se eligen a mano. Los comandos están en Defining commands.

2Project status

Terminal → Run Task… → Project status. Corre scripts/sandbox-status.sh y muestra oc whoami, el proyecto y la cuota. Las cuotas también cuentan el pod del workspace. Confirmá el CLI con openshell --version (no existe el subcomando openshell version). El nombre de la tarea queda en inglés porque es el texto del IDE.

3Ask Granite

La tarea Ask Granite corre scripts/sandbox-ask.sh curl. El token es oc whoami -t y no se escribe en git. TLS usa la CA de servicio. No hay un hostname fijo de modelo compartido. Definí la URL base primero:

export SANDBOX_MODEL_BASE=https://<predictor>.<namespace>.svc.cluster.local:8443/v1

El script lista /v1/models y manda un chat completion. La guía de Red Hat es consumir los modelos con GPU del sandbox.

4Ask with ask.py

La tarea Ask with ask.py hace el mismo descubrimiento y después corre python3 examples/ask.py con OPENAI_BASE_URL, MODEL_NAME, RHOAI_API_TOKEN y SSL_CERT_FILE. También necesita SANDBOX_MODEL_BASE. El prompt del script es una frase en español.

5Clean

La tarea Clean borra objetos con la etiqueta app.kubernetes.io/part-of=hello-openshell. No borra modelos compartidos ni el workspace.

Gateway. Un proyecto de Developer Sandbox no puede crear CRDs, namespaces ni ClusterRoles, y agents.x-k8s.io no está servida. El chart 0.1.8 se detiene ahí, así que el gateway no se instala. openshell --version funciona después de instalar el CLI. openshell status necesita un gateway.
