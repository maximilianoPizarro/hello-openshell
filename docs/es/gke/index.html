OpenShell desde Cloud Shell

Cloud Shell es el cliente. El clúster es un GKE Standard en tu proyecto de Google Cloud. Sigue facturando aunque cierres la sesión. No es Developer Sandbox.

1Crear el clúster

Autopilot suele rechazar el runtime del sandbox. Ubuntu es la imagen de nodo de esta guía. No uses deploy/openshift-scc-values.yaml. Ese archivo es para la SCC restricted-v2 de OpenShift.

export ZONE="${ZONE:-us-central1-a}"
export CLUSTER="${CLUSTER:-openshell}"
gcloud container clusters create "${CLUSTER}" \
  --zone "${ZONE}" \
  --machine-type e2-standard-2 \
  --num-nodes 2 \
  --image-type UBUNTU_CONTAINERD
gcloud container clusters get-credentials "${CLUSTER}" --zone "${ZONE}"

2Agent Sandbox y el gateway

El chart no instala el CRD. Podés aplicarlo porque administrás este clúster. Si falta helm, instalá Helm 3 antes.

kubectl apply -f https://github.com/kubernetes-sigs/agent-sandbox/releases/download/v1.0.10/sandbox.yaml
kubectl -n agent-sandbox-system rollout status deployment/agent-sandbox-controller --timeout=180s
helm upgrade --install openshell \
  oci://ghcr.io/nvidia/openshell/helm-chart \
  --version 0.1.8 \
  --namespace openshell \
  --create-namespace
kubectl -n openshell rollout status statefulset/openshell --timeout=300s

3CLI y mTLS

Cloud Shell es Debian. Usá el binario musl, no el instalador de Fedora. Dejá el port-forward en otra terminal. Copiá openshell-client-tls como en el módulo de OpenShift, con kubectl en lugar de oc.

mkdir -p "${HOME}/.local/bin"
curl -fL https://github.com/NVIDIA/OpenShell/releases/download/v0.1.8/openshell-x86_64-unknown-linux-musl.tar.gz \
  | tar -xz -C "${HOME}/.local/bin"
export PATH="${HOME}/.local/bin:${PATH}"
openshell --version
kubectl -n openshell port-forward svc/openshell 8080:8080
openshell gateway add https://127.0.0.1:8080 --local --name gke
openshell gateway select gke
openshell status

4Prueba

Un sandbox que solo imprime confirma el gateway. El kernel del nodo tiene que permitir Landlock. Si el log nombra Landlock o seccomp, ese nodo no puede correr un sandbox de OpenShell 0.1.8. La policy fija usuario y grupo 65532 para la imagen hardened.

openshell sandbox create \
  --name model-check \
  --from registry.access.redhat.com/hi/python:3.12 \
  --policy deploy/hi-python.policy.yaml \
  -- /usr/bin/python3.12 -c 'print("ok")'

5Borrar el clúster

Cerrar Cloud Shell no borra el clúster.

gcloud container clusters delete "${CLUSTER}" --zone "${ZONE}"
