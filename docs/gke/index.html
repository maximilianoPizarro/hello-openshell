OpenShell from Cloud Shell

Cloud Shell is the client. The cluster is a GKE Standard cluster in your Google Cloud project. It keeps billing after you close the shell. This is not Developer Sandbox.

1Create the cluster

Autopilot often rejects the sandbox runtime. Ubuntu is the node image used for the Landlock check. Do not pass deploy/openshift-scc-values.yaml. That file is for OpenShift restricted-v2.

export ZONE="${ZONE:-us-central1-a}"
export CLUSTER="${CLUSTER:-openshell}"
gcloud container clusters create "${CLUSTER}" \
  --zone "${ZONE}" \
  --machine-type e2-standard-2 \
  --num-nodes 2 \
  --image-type UBUNTU_CONTAINERD
gcloud container clusters get-credentials "${CLUSTER}" --zone "${ZONE}"

2Agent Sandbox and the gateway

The chart does not install the CRD. You can apply it because you administer this cluster. If helm is missing, install Helm 3 first.

kubectl apply -f https://github.com/kubernetes-sigs/agent-sandbox/releases/download/v1.0.10/sandbox.yaml
kubectl -n agent-sandbox-system rollout status deployment/agent-sandbox-controller --timeout=180s
helm upgrade --install openshell \
  oci://ghcr.io/nvidia/openshell/helm-chart \
  --version 0.1.8 \
  --namespace openshell \
  --create-namespace
kubectl -n openshell rollout status statefulset/openshell --timeout=300s

3CLI and mTLS

Cloud Shell is Debian. Use the musl binary, not the Fedora installer. Leave the port-forward running in another terminal. Copy openshell-client-tls the same way as the OpenShift module, with kubectl instead of oc.

mkdir -p "${HOME}/.local/bin"
curl -fL https://github.com/NVIDIA/OpenShell/releases/download/v0.1.8/openshell-x86_64-unknown-linux-musl.tar.gz \
  | tar -xz -C "${HOME}/.local/bin"
export PATH="${HOME}/.local/bin:${PATH}"
openshell --version
kubectl -n openshell port-forward svc/openshell 8080:8080
openshell gateway add https://127.0.0.1:8080 --local --name gke
openshell gateway select gke
openshell status

4Smoke test

A sandbox that only prints confirms the gateway. The node kernel still has to allow Landlock. If the sandbox log names Landlock or seccomp, that node cannot run OpenShell 0.1.8. The policy sets user and group 65532 for the hardened image.

openshell sandbox create \
  --name model-check \
  --from registry.access.redhat.com/hi/python:3.12 \
  --policy deploy/hi-python.policy.yaml \
  -- /usr/bin/python3.12 -c 'print("ok")'

5Delete the cluster

Closing Cloud Shell does not delete the cluster.

gcloud container clusters delete "${CLUSTER}" --zone "${ZONE}"

The click-through file the button opens is docs/cloudshell-tutorial.md.
