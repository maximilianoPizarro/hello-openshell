Developer Sandbox

Open the repo in a workspace. Startup installs the OpenShell 0.1.8 CLI and keeps the workspace if that step fails. Run Install OpenShell CLI to see the error. This cluster cannot host the gateway.

Open in Developer Sandbox

1Open the workspace

Use the button, or in Developer Sandbox open Dev Spaces and create a workspace from this repository. devfile.yaml requests 512Mi / 200m and limits the tools container to 4Gi / 2 CPUs. Storage is ephemeral. On start it runs scripts/install-openshell-cli.sh and puts openshell 0.1.8 on the PATH. The other tasks stay manual. Commands are documented in Defining commands.

2Project status

Terminal → Run Task… → Project status. It runs scripts/sandbox-status.sh and prints oc whoami, the project, and the quota. Resource quotas apply to the workspace pod too. Confirm the CLI with openshell --version (there is no openshell version subcommand).

3Ask Granite

Task Ask Granite runs scripts/sandbox-ask.sh curl. The token is oc whoami -t and is not written to git. TLS uses the service CA at /var/run/secrets/kubernetes.io/serviceaccount/service-ca.crt. There is no fixed shared-model hostname. Set the base URL first:

export SANDBOX_MODEL_BASE=https://<predictor>.<namespace>.svc.cluster.local:8443/v1

The script lists /v1/models and then sends one chat completion. Red Hat's walk-through of hosted models is Get started with consuming GPU-hosted large language models.

4Ask with ask.py

Task Ask with ask.py runs the same discovery, then python3 examples/ask.py with OPENAI_BASE_URL, MODEL_NAME, RHOAI_API_TOKEN, and SSL_CERT_FILE. It also needs SANDBOX_MODEL_BASE. The script's prompt is one Spanish sentence.

5Clean

Task Clean deletes objects labeled app.kubernetes.io/part-of=hello-openshell. It does not delete shared models or the workspace.

Gateway. A Developer Sandbox project cannot create CRDs, namespaces, or ClusterRoles, and agents.x-k8s.io is not served. Helm chart 0.1.8 stops there, so the gateway is not installed. openshell --version works after the CLI install. openshell status needs a gateway. A cluster you administer is the OpenShift AI module.
